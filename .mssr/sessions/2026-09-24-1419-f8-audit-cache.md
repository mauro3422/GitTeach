## Product correction

Remote repositories are not normal persistent worktrees anymore. GitTeach only needs enough source content to produce evidence and enough stable identity to compare the repository over time.

Durable remote state is therefore bounded to current commit/tree identity, commit time, filtered path/blob OIDs, derived evidence/hashes and later profile state. Existing local repositories are still analyzed in place.

## Implemented

- `giteach-repository-audit-cache-v1`: persistent bare blobless cache with current commit/tree plus path/blob-OID inventory.
- Refresh first resolves remote HEAD; changed heads fetch a shallow `--filter=blob:none` current tree.
- Snapshot comparison yields added/modified/deleted paths without downloading source bodies.
- Path metadata selects a bounded evidence set before hydration.
- Selected blobs hydrate in a temporary blobless Git store, are SHA-256 hashed/analyzed in memory and disappear when the temporary store is dropped.
- Integration verification proves hydrated source blobs do not enter the persistent audit cache.
- `giteach-repository-audit-history-v1`: portable pre-SQLite receipts of commit/tree/path/blob identity without source bytes or cache path.
- Earlier `giteach-repository-workspace-v1` remains tested reference/fallback only.
